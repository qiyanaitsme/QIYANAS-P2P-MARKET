# QIYANAS P2P PARSER

Парсер P2P обменов с Lolzteam Market с веб-интерфейсом и уведомлениями в Telegram.

## Возможности

- Парсинг P2P обменов с Lolzteam Market
- Фильтрация по направлению (пополнение/вывод маркета)
- Фильтрация по банкам России, Украины, Казахстана, Беларуси
- Фильтрация по суммам отдачи и получения
- Автоматическое обновление каждые 5 минут
- Уведомления в Telegram
- Адаптивный веб-интерфейс
